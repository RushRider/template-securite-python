# TP codes Sécurité Python

## Description

Projet contenant le rendu des TP sécurité python de CAUTENET Thyméo

## Installation

Faire un fork puis un clone du projet :

```bash
git clone https://github.com/RushRider/template-securite-python.git
```

Installer les dépendances :

```bash
cd template-securite-python
poetry lock
poetry install
```

## Utilisation

Lancer le projet :

```bash
poetry run tp1
```
